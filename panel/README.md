# Приватная панель

Next.js App Router, shadcn/ui `sidebar-07`, тема [Vercel](https://tweakcn.com/r/themes/vercel.json).

## Запуск

Требуется Node.js 22.13 или новее. Проверено на Node.js 26.

```sh
npm ci
npm run dev
```

Команда запускает Next.js на loopback-интерфейсе и отдельный worker. Откройте адрес из вывода Next.js. Если порт 3000 занят, dev-сервер выберет следующий.

```sh
npm run test
npm run typecheck
npm run build
npm start
```

Панель предназначена для локального использования. Проверка Host запрещает доступ через внешний домен. Для сетевого развёртывания сначала добавьте авторизацию; простого изменения hostname недостаточно.

## Данные

SQLite, ключ шифрования и изолированные профили Chromium лежат в `~/.local/state/private-panel/` вне проекта. Для резервной копии остановите приложение и сохраните всю папку, включая `secret.key`. Ключи переводчиков зашифрованы AES-256-GCM; в интерфейс возвращается только признак наличия ключа.

Необязательные настройки из `.env.local`:

- `PANEL_DATA_DIR`: абсолютный путь к локальным данным.
- `PANEL_CHROMIUM_PATH`: путь к Chromium, если он не найден в стандартных Linux-путях.

## Сбор

Источники продавцов: LDXP/CatFK, 16688, Kami/ACG-Faka, Dujiao-Next и JSON-фиды. Каталоги агрегаторов раскрываются автоматически через AIhaotan, FindAI, AIDeal, AIbijia, CardNav, Lowb, OpenPrice, PriceAI и AI Price Memory; HTML-каталоги проверяются отдельно. Для LDXP/CatFK проходят все типы `card`, `article`, `resource` и `equity`. Фид — массив либо объект `items`; у товара обязательны `id`, `name`, `url`.

После добавления источник сразу попадает в автоматический обход. Worker работает независимо от открытой страницы и продолжает проходить каталог продавца, каталоги агрегаторов и переводить новые позиции. Две последовательные полные проверки без товара помечают его снятым; частичный обход не удаляет позиции. В истории записываются изменения цены, валюты и наличия.

Для проверки источника выберите «Открыть сессию»; Chromium сохранит сессию локально, после чего автоматический обход продолжится. Нужен графический сеанс. Автоматический обход CAPTCHA не реализован.

## Перевод

- MyMemory: без ключа, ограничение сервиса 5 000 символов в день, с email — 50 000. Используются только запросы перевода `get`; публикация в память переводов `set` не выполняется.
- Gemini: ключ из AI Studio, модель задаётся в настройках. Для контекстного перевода используется глоссарий, JSON-схема и проверка ответа. Бесплатные лимиты зависят от модели и проекта.
- DeepL: собственный API-ключ. Ключи старого Free-тарифа и новых API-тарифов направляются на соответствующий хост. Доступная квота определяется тарифом аккаунта.
- OpenAI-совместимый API: пакетный потоковый перевод только названий; модель и HTTPS-адрес задаются в настройках. Ключ хранится зашифрованным.

Приложение учитывает локальный дневной бюджет символов и кеширует переводы. Квота сервиса может также расходоваться другими приложениями. Оригиналы сохраняются. Обычный машинный перевод и неоднозначные ответы помечаются для проверки. Изменение оригинала сбрасывает старый перевод. После правки словаря используйте «Перевести заново».

Курс CNY, USD и других валют загружается из XML ЦБ каждые шесть часов. Номинал учитывается, вычисления выполняются Decimal. Рубли — справочный пересчёт исходной цены; комиссии оплаты и банковский курс в него не включены.

## Проверка

`npm test` проверяет пагинацию, полноту снимков, варианты SKU, неизвестные остатки, историю, инвалидирование переводов, очередь, шифрование ключей, блокировку локальных адресов, байтовые лимиты перевода и курс с номиналом.
